# ML Project

## Overview

This project is part of a machine learning course. The goal is to collect data, preprocess it, train machine learning models, and evaluate their performance.

## Project Structure

* `data/` – Raw and processed datasets.
* `docs/` – Metadata file.
* `CreditApprovalApp/` – Jupyter notebooks containg preprocessing, training. As well as web app using Flask.

## Technologies

* Python
* Jupyter Notebook
* NumPy
* Pandas
* Scikit-learn
* Matplotlib
